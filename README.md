# 男人下一百层

纯前端、无构建工具的浏览器小游戏。对标经典「男人下一百层」：往下掉、踩平台、躲顶部尖刺，撑到第 100 层通关。

## 怎么玩

用浏览器直接打开 `index.html`。不需要安装依赖，也不需要打包。

- 键盘：`A` / `D` 或方向键左右移动，空格或 `P` 暂停
- 手机：点底部左右键，或按住画面左半边 / 右半边转向
- 踩金色弹簧台会弹得更高；红色碎裂台会先晃一下再消失
- 撞到顶部尖刺，或没踩住掉出画面，都会结束
- 最佳分存在浏览器本地，通关和失败都会更新

设计分析页：打开 `analysis.html`。
