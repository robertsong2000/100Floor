01

Overview

这是一份能玩的独立原型

仓库只有一次 Initial commit，没有 README、没有打包器、没有框架。本地打开 index.html 就能玩。它不是业务系统，也不是引擎模板，而是一个手感已经齐的「男人下一百层」对标作。

镜头不跟着角色走，而是世界整体上移。角色被往屏幕上方推，你必须不断往下找台子。撞到顶部尖刺，或没踩住掉出画面，都会结束。

  • 纯 HTML / CSS / Canvas / Web Audio
  • 桌面键盘 + 手机按键
  • 最佳分写入 localStorage
  • 到 100 层播放通关音阶

03

Game Loop

标准的一帧：更新，再画

  1. requestAnimationFrame 用性能时钟算 dt，并钳在 32ms，避免切回标签页时一帧跳太远。
  2. update(dt) 读按键、积分速度、施加重力、检测单向平台、滚动镜头、生成新台、结算层数。
  3. render() 天空渐变 → 平台 → 粒子 → 角色 → 顶部尖刺。暂停时盖一层半透明「暂停」。 
function loop(now) {
  const dt = Math.min(0.032, (now - state.lastTime) / 1000 || 0);
  state.lastTime = now;
  update(dt);
  render();
  requestAnimationFrame(loop);
}

页面加载会先静默铺好世界，再立刻暂停并显示遮罩。点「开始」时平台已经在，不会空场。

04

Systems

玩法不是数台阶，是算下落距离

分数与层数

每帧 score += max(1, floor(scroll / 4))。层数是 floor(score / 10) + 1，钳在 1 到 100。每 10 层播一次里程碑音效。

手感参数

重力 1450，水平加速 1800，最大速度 235。地面摩擦 0.82，空中 0.94。普通台回弹 -120，弹簧台 -650。

单向平台

只有下落、且上一帧脚还在台子上方时才落地。可以从台下穿过去。左右会穿屏：走出左边从右边出现。

失败与通关

撞尖刺：「撞到顶部尖刺了！」。掉出底部：「没踩稳，掉下去了！」。到 100 层显示「通关 100 层！这手感可以。」

普通台

米色。小弹一下，是基本落点。

弹簧台

金色。向上弹得更高，用来抢节奏。

碎裂台

红色。36 层后出现，踩上立刻消失。

05

Difficulty

四条参数一起加压

难度不是只加快滚动。镜头速度、平台间距、台宽、碎裂台会同时收紧，所以中后期会明显更挤。

镜头速度 平台间距 估算台宽
参数公式 / 规则效果
镜头速度78 + 层数 × 2.45越来越快地把你往上推
平台间距约 96 收到最低 64台与台更密，反应窗口更短
平台宽度随层数变窄，约 62–134落点更刁
平台种类36 层后加入碎裂台不能把每块台都当安全区

06

Audiovisual

没有素材包，声音是合成的

画面全是手绘 Canvas：深蓝到橙色的竖向天空、横条装饰、顶部一排尖刺、带阴影的色块平台、落地粒子。角色按状态切帧——站立第 0 帧，走动 1–4 帧，快速下落第 5 帧。

加载时会扫一遍像素 alpha，自动裁掉每帧黑边。图没到齐时用红矩形占位。声音全是 Web Audio：方波 / 三角波做音阶，噪声做碎裂和死亡。第一次按键才解锁音频，避开浏览器限制。

07

Review

手感完整，工程配套还薄

做得好的地方

  • 零依赖、单文件逻辑，state / update / render / sfx 分开，适合改玩法。
  • 重力、摩擦、弹簧、穿屏、单向平台都有，不是半成品。
  • 速度、间距、宽度、碎裂台一起加压，难度有节奏。
  • 键盘和触屏都覆盖，暂停、重开、最佳分齐全。
  • CSS 变量和 Canvas 用同一套配色，海报感完整。

明显问题

  • 通关 completeGame() 不写 localStorage，刷新可能丢掉通关分。
  • 落地蹲姿和晕眩两帧画了却没用上。
  • 碎裂台没有「晃一下再掉」，踩上立刻被滤掉。
  • 精灵图偏大；raw 图 1.4MB 完全没引用。
  • 没有 README / 许可证；空格暂停可能带动页面滚动。
总体判断：这是一个已经能玩的独立小游戏原型。架构就是「一个 HTML 页 + 一个游戏循环」，适合继续打磨手感和内容。下一步性价比最高的是：通关也存分、给碎裂台加短暂延迟、把落地 / 死亡帧用上、删掉未使用的 raw 图并补一份说明。
